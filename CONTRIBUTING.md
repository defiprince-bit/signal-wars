# Contributing
1. Fork, branch (`feat/...`), keep PRs small and focused.
2. Run `npm start` and test desktop + mobile (touch HUD) before opening a PR.
3. Include a screenshot/GIF for visual changes.
4. No wallets, tokens, real-money mechanics, or tracking. Keep the fan disclaimer intact.
5. Art: only submit assets you own or that are openly licensed; credit them in the PR.
Issues and ideas welcome — tag them `combat`, `art`, `map`, `story`, or `server`.
